# Лабораторная работа №2: Граф

**Описание:**  
Данная лабораторная работа реализует граф на Java с возможностью работы как с ориентированным, так и с неориентированным графом. Программа поддерживает:

- Добавление и удаление вершин
- Добавление и удаление рёбер
- Получение списка смежных верши
- Обход графа DFS и BFS
- Сохранение и загрузку графа в текстовый файл

**Используемые классы:**

- `Graph` — основной класс для работы с графом
- `MyList` — упрощённая реализация списка
- `MyStack` и `MyQueue` — вспомогательные структуры для DFS и BFS
- `Main` — класс с интерактивным меню для работы с графом
