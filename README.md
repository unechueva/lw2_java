# Лабораторная работа 2: Графы на Java

В этой работе реализован граф на Java с поддержкой ориентированных и неориентированных графов. Реализованы следующие возможности:

- Добавление и удаление вершин
- Добавление и удаление рёбер с весами
- Получение смежных вершин
- Обход графа в глубину (DFS) и в ширину (BFS)
- Сохранение и загрузка графа из файла

Используется собственная структура данных для хранения списков смежности и очередей/стеков.
